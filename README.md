# AUTOMATIC-SOLAR-PANEL-CLEANER
This helps to improve efficiency of the solar system through cleaning solar panel automatically and repeat monitor the cleaning status 

Out there most solar farms face a challenge with maintaining the output of a solar panels and we are saying this challenge can be solved by designing a system that can clean this solar panels automatically with just a minimum human intervation.
# Setup Guide
Install Arduino IDE on your computer and download this project code to run it
